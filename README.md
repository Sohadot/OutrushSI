# Outrush.si

Concept-led, static-first presentation of **Outrush.si**, a domain name offered for acquisition by **Sohadot**.

## Purpose

- Explain a timeless commercial thesis: **Intelligence in Motion**.
- Present only the documented meaning of *outrush*, with dictionary citations.
- Provide a distinct, `noindex, follow` acquisition page for proposals.
- Do **not** publish asking prices, offer floors, valuation figures, market speculation, or internal negotiating strategy.
- No existing product, company, users, partnerships, or standards are claimed.

## Pages

| Path | Function | Indexing |
|---|---|---|
| `/` | Concept, word meaning, brand directions, cited claims | `index, follow` |
| `/acquire/` | Dynadot offer link and direct email inquiries; transaction options | `noindex, follow` |

No Buy Now or automatic checkout button. The listing accepts proposals, subject to seller review. A transaction may subsequently be arranged through Dynadot or Escrow.com.

## Technical notes

This site uses plain HTML/CSS and a minimal progressive-enhancement script. No build pipeline, tracking, third-party JS, or JavaScript dependency is required. The hero diagram is a native inline SVG on desktop with an accessible compact presentation on mobile. Reduced-motion preferences disable the SVG motion.

Deploy from a static host supporting `/acquire/` directory index routing. Set `outrush.si` and `www` DNS/TLS in the hosting platform separately. **Do not change DNS by enabling a marketplace sale landing page**.

### Local preview

```bash
python3 -m http.server 8000
# Visit http://localhost:8000/ and http://localhost:8000/acquire/
```

### Pre-publication checks

1. Confirm the Dynadot URL still resolves to the correct listing.
2. Validate both acquisition actions and email composition on mobile.
3. Verify no prices or internal thresholds exist in HTML/CSS/JS/metadata.
4. Verify `/acquire/` retains `noindex, follow` and is absent from sitemap.
5. Complete trademark diligence in WIPO Global Brand Database and TMview before any exclusivity claim.
6. Confirm sale scope explicitly with the buyer: domain only unless otherwise agreed.
7. Test design, keyboard navigation, color contrast, and reduced-motion behavior.
